VulnScan
Mini Vulnerability Scanner

Educational Vulnerability Assessment

VulnScan is an educational, defensive vulnerability assessment tool designed to demonstrate the basic workflow of vulnerability scanning.

It scans a target for open ports, attempts to identify running services, checks a small set of well-known security misconfigurations and produces a clear report without attempting to exploit the target.

⚠

Only scan systems that you own or have explicit permission to test.
